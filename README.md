### H.Pylori Detection in Biopsy `Master's Project`
**Stack:** YOLOv8 • R-CNN • QuPath • Active Learning
- Engineered a hierarchical detection pipeline for detecting microscopic bacteria in massive Whole Slide Images (WSI).
- Implemented active learning, improving detection accuracy from **30% to 80%** and discovering **1,000+ correct annotations** missed by pathologists.
- Published and awarded **"Most Creative Research" at ICDD 2026**.

### Viktor LLM Router `European Hackathon League, TUM.ai`
**Stack:** RouteLLM • Gradient Boosted Classifier • TF-IDF
- Built an explainable, offline LLM router in 24 hours with a 5-person team, solving Viktor.com's co-founder's challenge.
- Achieved **~40% cost reduction** vs baseline (held-out evaluation).
- Extended post-event: paired semantic TF-IDF features with metadata in a GBC, improving routing accuracy and saving cost by **60%+**.

### Google Tunix Hackathon `Reasoning with Small Language Models`
**Stack:** Gemma 2B • GRPO • PEFT
- Led a team to a **Top 3 Medal** among 400+ participants.
- Built a memory-efficient GRPO fine-tuning pipeline, raising Gemma 2B's GSM8K accuracy to **71.3%**.
- Designed an Active Review mechanism (1:1 new-to-historical ratio) to counter catastrophic forgetting, and a consensus-voting step that lifted accuracy **8–11%** at zero additional training cost.

### CAIRA: RAG-Powered AI Mentor `THWS`
**Stack:** Qwen 1.5-7B • VLLM • FastAPI • Docker
- Architected a privacy-first, on-premise RAG pipeline to process administrative documents for international students.
- Achieved a **12x latency reduction (60s to <5s)** by migrating to VLLM and serving via FastAPI behind Nginx.
- Built a bilingual (English/German) student onboarding interface.

### BMW Lessons Learned System `Quality Analysis`
**Stack:** GPT-4o • SQLite Vector Search • React • Docker
- Unified retrieval across 3 data sources to automate quality insight generation for manufacturing defects.
- Engineered a **Hybrid RAG pipeline** using SQLite Vector Search and GPT-4o for context-aware analysis.
